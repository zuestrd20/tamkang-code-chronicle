# 暮光編譯 · Tamkang Code Chronicle

原創繁體中文校園劇情 RPG。成年虛構主角姜彥廷與夥伴追查「潮汐協定」，在三處可探索區域尋找未完成心願背後的答案。

**遊玩：** https://zuestrd20.github.io/tamkang-code-chronicle/

## 完整篇章

- 校園廣場、數位圖書館、運算核心：三張可步行地圖
- 原創人物對話、劇情選擇、隊友羈絆及章節結局
- 三人隊伍，技能、道具、成長、敵方行動預告與五場固定劇情戰鬥
- 邏輯謎題、任務日誌、免費休息補給與可重試戰鬥
- 本機自動／手動存檔、讀檔及重玩確認
- 原創生成背景與角色立繪、程式繪製地圖與敵人、Web Audio 合成樂曲及音效
- 鍵盤、地圖點擊與觸控方向／目的地按鈕

## 操作

方向鍵或 WASD 移動；Enter、空白鍵或 E 互動／繼續對話。Esc 關閉選單。點地面步行、點地點按鈕自動前往互動。戰鬥先看對手預告，再選攻擊／技能／道具／防禦；多目標技能及道具另選目標。音樂預設關閉，需使用者按鈕啟用。

存檔僅留在目前瀏覽器的 localStorage。清除網站資料會移除存檔；私人模式或儲存限制可能無法保存。讀檔不需要帳號或後端。遊戲不收集個人資料。

## 虛構與素材聲明

姜彥廷（22 歲）設定為淡江大學資工系四年級學生；林映禾（22 歲）、周以澄（23 歲）及其他人物均為原創成年虛構角色。沒有調查同名真人，劇情並非任何真實人物經歷。校園空間及事件均為架空示意，不是實際校園導覽；本作非學校官方作品，也不宣稱校方背書。

只借鑑經典角色扮演遊戲的探索、敘事、隊伍與回合制戰鬥等一般玩法。未使用《仙劍奇俠傳》的角色、情節、地圖、台詞、音樂、美術或程式碼。

背景與立繪詳見 [ART_CREDITS.md](ART_CREDITS.md)。所有地圖和敵人程式圖形為本專案原創。音樂為原創 Web Audio 音列／合成器，不含第三方錄音或商業遊戲曲目。字型：Google Fonts Noto Sans TC／Noto Serif TC（SIL Open Font License），無網路時回退系統字型。

## 本機啟動與測試

零前端套件依賴，使用現代瀏覽器與靜態伺服器：

```sh
python3 -m http.server 8080
# 開啟 http://localhost:8080
node tests-engine.mjs
node tests-extra.mjs
```

GitHub Pages 使用 main 分支根目錄原生部署，無自訂部署 workflow。測試證據及限制見 [QA.md](QA.md)。
